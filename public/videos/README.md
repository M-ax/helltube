# MLG Intervention reaction

`intervention.mp4` is a local H.264 copy of the six-second green-screen MW2 Intervention quickscope clip:
https://www.youtube.com/watch?v=wJ_Igr3Y0Os
Title: intervention mw2 con sonido green screen
Uploader: Mlg life swag 420 blaze it

The narrow black side borders are cropped (624×352 from the 640×352 source).
The original green background is keyed to transparency in the reaction canvas.
Audio is extracted separately into `../sounds/intervention.mp3`, normalized to
-18 LUFS / -2 dBTP, mono 44.1 kHz at 96 kbps, and scaled by viewer volume.

Original Call of Duty game artwork and audio belong to their respective rights holders.
The application serves these files locally and makes no YouTube requests during reactions.
A higher-resolution silent version was also located, but is not used:
https://www.youtube.com/watch?v=xVrayfJ_oI8

`intervention.webm` is the same silent clip encoded as VP9 for embedded browsers
without H.264 support. The reaction chooses it when the browser cannot decode AVC.
