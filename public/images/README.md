# Reaction artwork

`csgo-flashbang.png` is Valve's Counter-Strike flashbang inventory image, sourced from
https://github.com/ByMykel/counter-strike-image-tracker/blob/main/static/panorama/images/econ/weapons/base_weapons/weapon_flashbang_png.png.
The original artwork belongs to Valve. It is served locally for the reaction and button icon.

`joe-biden-walking.png` is an AI-generated parody cutout with a transparent RGBA
background, created using the built-in imagegen tool. It is not a photograph of a
real event. The same local asset is used for the reaction and its button icon.

Generation prompt:
> Use case: photorealistic-natural. Asset type: transparent PNG cutout sprite for a humorous video-player reaction. Create one isolated full-body photographic-style cutout of Joe Biden, recognizable face and white hair, wearing a navy blue suit, white shirt, blue tie, and black shoes. He is in a slightly awkward mid-walking pose, torso in a three-quarter view facing to the RIGHT with his face still recognizable, arms loosely bent, one shoe forward, both complete shoes visible. Slight puzzled neutral expression. This is a playful parody paper-cutout asset, not a real event photo. Frame the entire single person closely with a little transparent padding around all edges. Actual transparent alpha background, no backdrop, no floor, no cast shadow, no objects, no captions, no text, no logos, no watermark. Portrait aspect ratio, about 512 by 1024 pixels. One person only, a single pose only.
